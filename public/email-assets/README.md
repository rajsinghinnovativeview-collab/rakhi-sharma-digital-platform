# Email images for Rak.Hi Arts

Place these three optimized JPEG files in this directory:

- `rakhi-email-logo.jpg` — original Forest Gold Monogram logo, scaled for email use
- `rakhi-email-botanical.jpg` — original botanical artwork, cropped as email header
- `rakhi-email-artwork.jpg` — original Orchha watercolour artwork, cropped as a footer artwork

Source files were supplied by the website owner. Once uploaded here and merged to main, the public image URLs are:

- https://raw.githubusercontent.com/rajsinghinnovativeview-collab/rakhi-sharma-digital-platform/main/public/email-assets/rakhi-email-logo.jpg
- https://raw.githubusercontent.com/rajsinghinnovativeview-collab/rakhi-sharma-digital-platform/main/public/email-assets/rakhi-email-botanical.jpg
- https://raw.githubusercontent.com/rajsinghinnovativeview-collab/rakhi-sharma-digital-platform/main/public/email-assets/rakhi-email-artwork.jpg

**Important:** These URLs will not work until the actual JPG binaries are uploaded. Do not deploy email template references to non-existent files.

For branded email use of these files, use https://rakhiart.in/email-assets/... when they are included in the deployed site's `public/` directory and verified over HTTPS. Cloudflare deployment must include all images; test unauthenticated access and check response content-type `image/jpeg`.

The Resend sender remains `Rak.Hi Arts <noreply@rakhiart.in>`, and OTP generation / verification stays in Apps Script.
